# Tracker

Personal tracker for gym, food and projects. Phone-first, installable (PWA), works offline.
Data is stored locally on each device; use Settings → Export/Import to move it.

```
npm install
npm run dev      # local dev, also reachable from your phone on the same Wi-Fi
npm run build    # production build in dist/
```

Pushing to `main` deploys to GitHub Pages automatically.
